# 🌐 File Transfer Server (Linux)

A multi-client File Transfer Server built in C using socket programming. This server allows clients to request files, and it sends the requested file over a TCP connection.

---

## 🚀 Features

- 📡 TCP-based client-server communication  
- 📁 Sends requested file to client  
- ⚡ Handles multiple clients using process creation (fork)  
- 🔍 Validates file existence before sending  
- 📊 Sends file size before actual data transfer  

---

## 🛠️ Technologies Used

- C Programming  
- Linux System Programming  
- Socket Programming (TCP/IP)  
- Process Management (fork)
